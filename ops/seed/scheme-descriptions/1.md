# Navigation

General entry point for **time series** that are not part of a specific reporting framework.

- **ECO – Economy**: macroeconomic indicators, e.g. BIS policy rates (daily import via the *Processes* menu)
- Each dataflow is linked to one category via an SDMX categorisation (also available through the read API, see **API** in the menu).

Data stages: economists see **Beta** (released) data only; data managers additionally see **Alpha**.
