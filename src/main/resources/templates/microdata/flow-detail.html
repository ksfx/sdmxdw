Add group field

For attributes that can occur multiple times per record (e.g. several items of collateral per loan). Several fields sharing the same group code belong together and repeat as a set - no facet, no new table, stays within the same generic record.

Add reference field

For fields whose value is the entity ID of a record in another microdata flow (e.g. "Gegenpartei" on a loan) - instead of a fixed codelist, the value is validated against the target flow. Linking flows (e.g. Rahmen-Sicherheit) usually consist of just two such reference fields.

Aggregation bridge to SDMX

Linked dataflow: . The target DSD's non-time dimensions must line up positionally with Facet1..4, and the target DSD needs exactly one measure (the count).

Running the aggregation is a data operation: use "Aggregate & publish to SDMX" on the flow page in the explorer.
