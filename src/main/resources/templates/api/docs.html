Read API

Scripts read data from SDMxDW via : time series with the standard SDMX REST API (usable with Python sdmx1 and R rsdmx), microdata with a REST API that follows the same conventions. Machine-readable description: OpenAPI.

Authentication

Create a personal API token under Profile → API tokens and send it with every request:

Authorization: Bearer sdw_...

Clients without header support can send the token as basic-auth password (any user name). A token has the rights of its owner: everyone sees published (Beta) data; Datenmanager tokens can additionally read Alpha data with stage=ALPHA. Missing or invalid tokens get 401, Alpha requests of other users 403. Keep tokens out of notebooks and repositories, e.g. in an environment variable SDMXDW_TOKEN.

Time series (SDMX REST)

Structure queries

/dataflow/{agency}/{id}/{version}SDMX 2.1 style; types dataflow, datastructure, codelist, conceptscheme, categoryscheme, categorisation. Output SDMX-ML 2.1.
/structure/{type}/{agency}/{id}/{version}SDMX 3.0 style, output SDMX-ML 3.0.
?references=none (default), parents, parentsandsiblings, children, descendants, all or a type name.

Wildcards: all / *; versions latest / ~. The agency SDMXDW stands for all agencies (sdmx1 sends its source id as agency).

Data queries

/data/{flowRef}/{key}SDMX 2.1 style; flowRef ID, AGENCY,ID or AGENCY,ID,VERSION; key like Q.DEMO01._T.39+40.26 (+ = or, empty = all).
/data/dataflow/{agency}/{id}/{version}/{key}SDMX 3.0 style, additionally c[DIM]=A,B and c[TIME_PERIOD]=ge:2020-Q1+le:2024-Q4.
startPeriod, endPeriodTime range.
asOfData as published at that time: 2026-06-30 (end of day, UTC), 2026-06-30T12:00 or ISO instant.
firstNObservations, lastNObservationsPer series.
detail=serieskeysonlySeries keys without observations.
stage=ALPHAUnpublished data, Datenmanager only.

Formats

Accept headerformat=Format
application/vnd.sdmx.genericdata+xml;version=2.1genericxmlSDMX-ML 2.1 GenericData (default on 2.1 paths)
application/vnd.sdmx.structurespecificdata+xml;version=2.1xml&sdmxVersion=2.1SDMX-ML 2.1 StructureSpecificData
application/vnd.sdmx.data+xml;version=3.0.0xmlSDMX-ML 3.0 StructureSpecificData (default on 3.0 paths)
application/vnd.sdmx.data+csv;version=2.0.0 / 1.0.0csvSDMX-CSV 2.0 / 1.0
application/vnd.sdmx.data+json;version=1.0.0jsonSDMX-JSON 1.0

SDMX 2.1 formats know a single primary measure: the first measure is delivered as OBS_VALUE, further measures as observation attributes. SDMX 3.0 formats and SDMX-CSV 2.0 keep all measures under their own ids.

Microdata

/microdataCatalog of all microdata flows (JSON).
/microdata/{flowRef}/structureFields with types, codelists, obligation; repeating groups; relations: which field references which flow (references) and which flows reference this one (referencedBy); available reporting periods.
/microdata/{flowRef}Main table: one row per ENTITY_ID and REPORTING_PERIOD, one column per field.
/microdata/{flowRef}/groups/{group}Repeating group (e.g. several collaterals per loan) as child table: ENTITY_ID, REPORTING_PERIOD, ITEM_NO + group fields.
reportingPeriodOne or more periods (2026-Q3,2026-Q2) or latest.
c[FIELD]=A,BFilter on a (non-group) field, several filters are combined with AND.
asOf, stageAs for time series.
limit, offsetPaging over records; header X-Total-Count, Link: rel="next".
formatcsv (SDMX-CSV layout, default), json, parquet (typed columns; recommended for large volumes).

References are delivered as ids and not pre-joined: join e.g. INSTRUMENT.GEGENPARTEI on GEGENPARTEI.ENTITY_ID and REPORTING_PERIOD, as given in joinOn of the structure response.

Python

sdmx1 (time series)

import os, sdmx

sdmx.add_source({"id": "SDMXDW", "name": "SDMxDW", "url": "[[${baseUrl}]]"}, override=True)
client = sdmx.Client("SDMXDW")
client.session.headers["Authorization"] = "Bearer " + os.environ["SDMXDW_TOKEN"]

flows = client.dataflow()                        # all dataflows
msg = client.dataflow("DF_KRED", agency_id="SNB")  # dataflow incl. DSD, codelists, concepts
dsd = msg.dataflow["DF_KRED"].structure
data = client.data("DF_KRED", key="Q.DEMO01._T.39.26", dsd=dsd, params={"startPeriod": "2025-Q1"})
df = sdmx.to_pandas(data)

# parameters outside the SDMX standard (asOf, stage) via a full URL
old = client.get(url="[[${baseUrl}]]/data/DF_KRED/Q.DEMO01._T.39.26?asOf=2026-06-30")

pandas / requests (time series and microdata)

import io, os, requests, pandas as pd

s = requests.Session()
s.headers["Authorization"] = "Bearer " + os.environ["SDMXDW_TOKEN"]
base = "[[${baseUrl}]]"

ts = pd.read_csv(io.StringIO(s.get(f"{base}/data/SNB,DF_KRED/Q.DEMO01._T..26?format=csv").text))

structure = s.get(f"{base}/microdata/SNB,MDF_EKE_INSTRUMENT/structure").json()
r = s.get(f"{base}/microdata/SNB,MDF_EKE_INSTRUMENT", params={"reportingPeriod": "latest", "format": "parquet"})
instruments = pd.read_parquet(io.BytesIO(r.content))
r = s.get(f"{base}/microdata/SNB,MDF_EKE_GEGENPARTEI", params={"reportingPeriod": "latest", "format": "parquet"})
counterparties = pd.read_parquet(io.BytesIO(r.content))
joined = instruments.merge(counterparties, left_on=["GEGENPARTEI", "REPORTING_PERIOD"],
                           right_on=["ENTITY_ID", "REPORTING_PERIOD"], suffixes=("", "_GP"))

R

rsdmx (time series)

library(rsdmx)
auth <- list(Authorization = paste("Bearer", Sys.getenv("SDMXDW_TOKEN")))
base <- "[[${baseUrl}]]"

flows <- as.data.frame(readSDMX(paste0(base, "/dataflow/all/all/latest"), headers = auth))
dsd   <- readSDMX(paste0(base, "/datastructure/SNB/DSD_KRED/latest?references=children"), headers = auth)
data  <- as.data.frame(readSDMX(paste0(base, "/data/SNB,DF_KRED/Q.DEMO01._T.39.26?startPeriod=2025-Q1"), headers = auth))

httr2 + arrow (microdata)

library(httr2); library(arrow)
req <- request(paste0(base, "/microdata/SNB,MDF_EKE_INSTRUMENT")) |>
  req_auth_bearer_token(Sys.getenv("SDMXDW_TOKEN"))

structure <- resp_body_json(req_perform(req |> req_url_path_append("structure")))
tmp <- tempfile(fileext = ".parquet")
req_perform(req |> req_url_query(reportingPeriod = "latest", format = "parquet"), path = tmp)
instruments <- read_parquet(tmp)
