Processes

Git repository

The process folder can be a sub-folder of a Git repository. Saving in the app commits (with you as author) and pushes; changes made in an IDE come in with Pull. Every run records the commit it ran with. Process metadata (steps, schedules, parameters) stays in the database.

Linking clones the repository. Process folders that do not exist in the sub-folder yet are added in one commit and pushed; existing ones in the repository are used as they are.
